# Applications (local only)

Each job you apply to gets its own folder here, for example:

```text
applications/acme_solutions_engineer/
  Rithwik_Gokhale_Resume_Acme_Solutions_Engineer.pdf
  Rithwik_Gokhale_Cover_Letter_Acme_Solutions_Engineer.pdf
  resume/
  cover_letter/
  notes/
```

**This directory is gitignored** except for `_TEMPLATE_COMPANY_ROLE/`. Real application folders (company-specific resumes, cover letters, and strategy notes) are not pushed to GitHub.

Copy `_TEMPLATE_COMPANY_ROLE/` to `applications/company_role/` when starting a new application. See `docs/17_APPLICATION_FOLDER_STRUCTURE.md`.

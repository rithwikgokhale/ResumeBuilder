# Solutions Architect / Application Architect — Bullet Bank

## When to use

JDs that emphasize designing fit-for-purpose technical solutions, integration architecture, enterprise systems, regulated environment delivery, SaaS/on-prem/hybrid deployment design, or "Application Architect" / "Solutions Architect" titles.

Persona reference: [`../10_ROLE_PERSONAS_RESUME_STRATEGY.md` §5 Solutions Architect](../10_ROLE_PERSONAS_RESUME_STRATEGY.md).

**Honest framing:** Use "architected" only where Rithwik truly designed solution architecture, integration approach, workflow design, or deployment structure. Do **not** imply formal enterprise architect scope unless the JD language supports it.

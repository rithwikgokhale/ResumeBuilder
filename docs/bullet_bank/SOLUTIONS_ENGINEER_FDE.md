# Solutions Engineer / Forward Deployed Engineer — Bullet Bank

## When to use

JDs that ask for customer-embedded technical work: pre-sales technical demos, technical discovery, integrations validation, deployment-heavy field engineering, customer success engineering, or "Forward Deployed Engineer" titles at AI/B2B SaaS companies.

Persona references:
- [`../10_ROLE_PERSONAS_RESUME_STRATEGY.md` §1 Solutions Engineer](../10_ROLE_PERSONAS_RESUME_STRATEGY.md)

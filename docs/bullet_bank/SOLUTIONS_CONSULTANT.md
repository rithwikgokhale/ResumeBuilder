# Solutions Consultant / Implementation Consultant — Bullet Bank

## When to use

JDs that emphasize delivering software solutions to customers: requirements gathering, configuration, customer workshops, UAT, training, go-live, hypercare, change management. Common titles: "Implementation Consultant," "Solutions Consultant," "Customer Success Engineer (delivery-heavy)," "Onboarding Consultant."

Persona reference: [`../10_ROLE_PERSONAS_RESUME_STRATEGY.md` §4 Solutions Consultant](../10_ROLE_PERSONAS_RESUME_STRATEGY.md).

**Honest framing:** Lead with implementation + adoption. Keep enough technical edge (APIs, SQL, automation, integrations) so it doesn't read like a generic management consultant resume — that's Rithwik's edge over generic consultants.
